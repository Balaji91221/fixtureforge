# Changelog

## 0.2.1 — 2026-10-13

- Updated npm installation and pinned MCP launch instructions.
- Updated package and lockfile versions for the npm release.
- Runtime behavior is unchanged from 0.2.0; existing GitHub 0.2.0 release assets remain available.

## 0.2.0 — local build, 2026-10-13

- Added SQLite environment persistence, atomic mutations, owner/actor credentials,
  namespaces, deterministic simulation clock, reset/restore, revocation and cleanup.
- Added ticket search/get/update/assignment/close and replay-validated snapshots.
- Added schema-checked scenarios, known solutions, deterministic task predicates,
  event timelines, state diffs, escaped HTML reports and a scenario runner.
- Added scoped HTTP and MCP adapters; retained explicit insecure in-memory demo mode.
- Added CI/release files and clean package verification. No npm publication yet.

## 0.1.0 — local build

- Implemented an in-memory ticket domain and localhost demonstration API.
